The main responsibility of the database is to store data and make it accessible easily. But, if the data is being stored randomly, this make harder to manage it. The data should be stored using technics. One of the most successor of the technic is B-Tree. 

B-Tree In computer science, B-Tree is a self-balancing tree data structure that maintains sorted data and allows discovery, insertions, and deletions. B-Tree is adopting the binary search tree do, allowing nodes to have more than two children.
